# Fiber Pay-to-Unlock Report

This repository contains a short report on the Fiber encrypted-data payment tutorial shown in the submitted screenshots.

Open the report: [Fiber Testnet Pay-to-Unlock](report/fiber-testnet-pay-to-unlock.md)
